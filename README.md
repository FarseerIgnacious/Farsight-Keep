# Farsight Keep

A fully offline desktop companion app for D&D 5e Dungeon Masters. Manage encounters, 
build monsters, NPCs, PCs, and spells, and run campaigns. No internet connection 
required, no account, no data leaving your machine.

Farsight Keep ships empty. Import your own data via **Game Master 5e (no affiliation)** 
XML exports, or build everything from scratch using the in-app creation tools.

## Download

Grab the latest release for your platform from the [Releases page](https://github.com/FarseerIgnacious/Farsight-Keep/releases/latest):

| Platform | File |
|---|---|
| **macOS** | `Farsight Keep-*-Mac.dmg` |
| **Windows** | `Farsight Keep-*-Windows-Setup.exe` |
| **Linux** | `Farsight Keep-*-Linux.AppImage` or `.deb` |

Builds are currently unsigned. On macOS, right-click → Open the first time (or run 
`xattr -cr` on the app) to bypass Gatekeeper. On Windows, click "More info," then 
"Run anyway" if SmartScreen warns you.
